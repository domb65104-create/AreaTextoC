(EN) AreaTextoC

Utility for AutoCAD and Civil 3D that automatically calculates area, inserts centered labels, and copies values directly to Excel.

Installation
Run NETLOAD.
Load AreaTextoC.dll.
Run AREATEXTOC.
Features

✅ Automatically calculates the area.

✅ Inserts a centered label inside the selected shape.

✅ Copies the calculated value to the clipboard for direct pasting into Excel using Ctrl+V.

✅ Compatible with polylines, circles, ellipses, and regions.

History
The original idea for this tool was born around 2010 while preparing embankment and earthwork plans using Land Desktop.

The original source code was eventually lost among old backups and storage media that I no longer use regularly.

The version published in this repository is a modern reinterpretation of that original idea for current versions of AutoCAD and Civil 3D.

In the end, it was never about programming.

Nor about changing the result.

It was about having more time for a coffee. ☕
